## 🚀 Project Overview

A fully dynamic **Student Management System** built using **PHP & MySQL** with a clean admin panel.  
It allows administrators to manage students efficiently with authentication and full CRUD operations.

---

## ✨ Features

- 🔐 Admin Login & Logout System
- 👨‍🎓 Add New Students
- 📋 View All Students
- ✏️ Edit Student Records
- 🗑️ Delete Students
- 🔍 Search & Filter Students
- 📚 Course Management (inside student records)
- 🖼️ Image Upload System
- 📊 Dynamic Dashboard (Total Students)
- 📱 Responsive UI using Bootstrap 5
- 🔒 Secure Session-based Authentication

---

## 🛠️ Tech Stack

- 💻 PHP (Core PHP)
- 🗄️ MySQL Database
