# 🎓 Student Management System (PHP & MySQL)

A fully dynamic Student Management System built using PHP and MySQL. This project helps manage student records efficiently with authentication, CRUD operations, image uploads, and a clean admin dashboard.

---

## 🚀 Features

- 🔐 Admin Login & Logout System
- 👨‍🎓 Add New Students
- 📋 View All Students
- ✏️ Edit Student Records
- 🗑️ Delete Students
- 🔍 Search Functionality
- 📚 Course Management (stored in student records)
- 🖼️ Image Upload for Students
- 📊 Dynamic Dashboard with Statistics
- 📱 Responsive UI using Bootstrap 5
- 🔒 Session-based Authentication (Secure Dashboard Access)

---

## 🛠️ Tech Stack

- PHP (Core PHP)
- MySQL Database
- HTML5, CSS3
- Bootstrap 5
- JavaScript
- Font Awesome Icons
